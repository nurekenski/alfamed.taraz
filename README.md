# Alfa-Med Тараз — сайт

Тараз қаласындағы Alfa-Med медициналық-диагностикалық орталығының бір беттік сайты.
Қазақ және орыс тілдерінде (ҚАЗ / РУС ауыстырғышы), телефонға бейімделген.

## Мазмұны

- Басты блок, онлайн жазылу формасы (өтінім клиниканың WhatsApp-ына жіберіледі)
- Қызметтер: МРТ, КТ, зертханалық талдаулар, терапевт, ЖТД, үйден талдау алу
- Мамандар (12 адам, карточкалар слайдері)
- ОСМС / ақылы қызмет, зертхана, мекенжайлар (2ГИС сілтемелерімен)
- Көмекші чат-бот (екі тілде, сайттағы деректермен жауап береді)
- Іздеу жолы, WhatsApp және телефон батырмалары

Сайт таза HTML/CSS/JS-пен жазылған: құрастыру (build) қажет емес, сервер керек емес.

## Құрылымы

```
index.html          — бүкіл сайт (стильдер, мәтін, скрипттер)

img/icon-512.png, img/apple-touch-icon.png — үлкен белгілер
img/team/01–12.jpg  — мамандардың фотолары
```

## GitHub Pages арқылы жариялау

1. GitHub-та жаңа репозиторий ашыңыз (мысалы, `alfamed-taraz`).
2. Осы буманы жүктеңіз:
   ```bash
   git remote add origin https://github.com/<аккаунт>/alfamed-taraz.git
   git push -u origin main
   ```
3. Репозиторийде **Settings → Pages → Build and deployment**:
   Source — `Deploy from a branch`, Branch — `main`, папка — `/ (root)` → **Save**.
4. 1–2 минуттан кейін сайт `https://<аккаунт>.github.io/alfamed-taraz/` мекенжайында ашылады.

Өз доменіңізді (мысалы, `alfamed-taraz.kz`) қоссаңыз: Settings → Pages → Custom domain.

## Мәліметті жаңарту

Барлығы `index.html` ішінде.

| Нені өзгерту | Қайдан іздеу |
|---|---|
| WhatsApp нөмірі | `const WHATSAPP = '77477518000';` |
| Мәтіндердің орысша аудармасы | `const RU = { ... }` сөздігі |
| Чат-бот жауаптары | `const KB = { ... }` (әр тақырыпта `k` — кілт сөздер, `a` — жауап) |
| Боттағы мамандар тізімі | `const DOCS = [ ... ]` |
| Мамандар карточкалары | `<section id="team">` бөлімі |
| Телефон, мекенжай | мәтін ішінде (`+7 747 751 80 00`, `Қонаев`) |

Мәтінді қазақша өзгерткенде `RU` сөздігіндегі сол мәтіннің кілтін де бірдей етіп өзгерту керек,
әйтпесе орыс тіліне ауысқанда ол жол аударылмай қалады.

## Деректердің дереккөздері

Сайттағы әр дерек расталған дереккөзден алынған. Тізімі `index.html` файлының басында
(`ДЕРЕККӨЗДЕР` түсініктемесі), әр мәлімет жанында белгі бар: `[Я]` Яндекс Карталар, `[2Г]` 2ГИС,
`[IG]` Instagram @alfamed.taraz, `[ТР]` мемлекеттік тізілім, `[КЛ]` клиниканың өз мәліметі.
